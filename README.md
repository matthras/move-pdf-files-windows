# move-pdf-files-windows
A .bat script (for Windows) that searches a target folder (and all subfolders) for PDF files, and then copies them all to a single (different) target folder.

The original intention for this was to move a Zotero directory full of research PDF files to a separate Dropbox folder so that I could access my research PDFs through shared cloud storage.

This script was generated by Claude.ai using the following prompt: `Give me a .bat script that searches a specified target directory (and all subdirectories) for PDF files, and then copies them to a different specified target directory. Include comments explaining each line or block of code.`

## How to Use (for a naive Windows user)

1. Click on 'copy_pdfs.bat', and click on 'Download raw file' towards the top-right corner. It should download into your default Downloads folder.
2. In your Downloads folder, right click on 'copy_pdfs.bat' and select 'Open in Notepad' (feel free to use your preferred text editor instead!)
3. On Line 15, replace the path name inside the quotation brackets with the folder containing your PDF files.
  * In Zotero, go Edit > Settings > Advanced > Data Directory Location to find the source folder name that looks similar in formatting. Copy and paste that into this line.
  * If you're choosing any other folder and want to get the file name, my way is to open the folder itself, then click on the bar that reads something like "<Computer Icon> > This PC > OS (C:) > Program Files > <username> > Folder-Containing-Your-PDFs". This should change to a file name that you can copy/paste into this line.
4. On Line 18, do the same as in the previous step, but for the folder that you want your PDF files to be in.
5. Save (Ctrl+S) and close the Notepad window.
6. Double click on 'copy_pdfs.bat'. A command window will open and scroll through all the PDF files that you've moved over.
7. Check your target folder to see if your files are there.

## Notes

* This exclusively targets only PDF files, but Zotero may have other references stored in different formats.
